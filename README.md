# The One-Liner Groan-Off

A make.fun bounty entry. `main.ts` writes a single one-line dad joke to `entry.txt`.

> My dad bod is just a father figure.

Run with `MAKEFUN_OUTPUT_DIR` set to choose where `entry.txt` is written (defaults to `/output`).
